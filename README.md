# QuizZap - Demo Version

Questa è la versione demo di QuizZap ospitata su Netlify a fini dimostrativi, pensata per mostrare soprattutto l'interfaccia utente e l'esperienza interattiva del progetto.

Per esplorare il codice sorgente completo e le implementazioni tecniche, consulta i branch dedicati:

- `quiz-zap-angular` — Versione completa in Angular con json-server.
- `quiz-zap-react` — Versione completa in React con json-server.
- `quiz-zap-fullstack` — Versione fullstack con backend dedicato (Angular + Spring Boot).
- `quiz-zap-netlify` (questo branch) — Versione statica per deploy Netlify.

La versione demo è accessibile al link: **[https://quiz-zap.netlify.app/]**.

I punteggi salvati durante la sessione appariranno nella classifica fino alla chiusura del browser.
